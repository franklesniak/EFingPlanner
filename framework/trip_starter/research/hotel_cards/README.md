# Hotel Cards

## What goes in this folder

One filled hotel comparison card for each place you might stay, one card to a file. You make them in Session 35, after you compare neighborhoods in Session 34.

Session 35 says how many cards are enough.

## Where the blank comes from

The blank is the [Hotel Comparison Card template](../../../templates/hotel_comparison_card.md). Copy it once for each place you compare, and fill in the copy.

That template is the only blank. Leave it as it is. Keep no spare blank in this folder, so you always know which page is the empty one.

## How to name each file

Name each file for the city and a short word about the place. Use lowercase letters, put an underscore where a space would go, and end with `.md`.

Two examples of the shape, with made-up names:

- `first_city_near_station.md`
- `first_city_by_the_park.md`

## Keep it honest and open

You compare. The adults book. Write only what you found, and leave a box open until you know. "Not decided yet", "unknown" and "ask an adult" are complete answers.

Nightly prices and cancellation rules change, so a grown-up checks them again before booking. Keep private details off every card, and write no booking or confirmation details anywhere, as the [privacy and safety](../../../docs/privacy_and_safety.md) page says.
