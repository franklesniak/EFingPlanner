# Attraction Cards

## What goes in this folder

One filled Attraction Research Card for each attraction or experience you research, one card to a file. You start them in Session 23. Session 25 helps you judge the reviews you find, and Session 26 sorts every card into a group.

Session 23 says how many cards make the set complete. It can take several sittings, and two cards in a sitting is a finished day.

## Where the blank comes from

The blank is the [Attraction Research Card template](../../../templates/attraction_research_card.md). Copy it once for each attraction, and fill in the copy.

That template is the only blank. Leave it as it is. Keep no spare blank in this folder, so you always know which page is the empty one.

## How to name each file

Name each file for the attraction or experience. Use lowercase letters, put an underscore where a space would go, and end with `.md`.

Two examples of the shape, with made-up names:

- `science_museum.md`
- `river_boat_ride.md`

If two places share a name, add the city to one of them.

## Keep it honest and open

Write only what you found. Your price guess stays as you wrote it, even when the checked price is different. Being off is normal. "Not decided yet", "unknown" and "ask an adult" are complete answers.

Ticket prices, opening hours and booking rules change. Check them again before anyone books. Keep private details off every card, as the [privacy and safety](../../../docs/privacy_and_safety.md) page says.
