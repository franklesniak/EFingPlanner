# Recommendations

This part of your kit holds your checkpoint recommendations. At each checkpoint, you recommend something to the grown-ups, and each recommendation has its own page here.

## One page for each checkpoint

- [Season recommendation](season_recommendation.md): Checkpoint 1, in Session 14.
- [City shortlist](city_shortlist.md): Checkpoint 2, in Session 22.
- [Top experiences](top_experiences.md): Checkpoint 3, in Session 27.
- [Route and trip length](route_and_trip_length.md): Checkpoint 4, in Session 32.
- [Itinerary review](itinerary_review.md): Checkpoint 5, in Session 46.
- [Final recommendation](final_recommendation.md): Checkpoint 6, in Session 52.

Each checkpoint session has a table with the same kind of prompts. Fill in the session's table or the page here, whichever you're using. You only need one of them.

Each page follows the four parts on the [How to Make a Recommendation](../../student_guide/how_to_make_a_recommendation.md) card: what you recommend, why, what it costs you, and what a grown-up still needs to check or decide.

## The decision log gets a record too

When the grown-ups decide, write a Decision Record for the checkpoint in your [decision log](../logs/decision_log.md). The recommendation lives here, and the decision lives there. That way, the checkpoints and the log tell the same story.

## One artifact, one home

Each recommendation lives on its own page here. Near the end, the finished pages in `outputs/` carry the short version forward from these pages. Keep one copy of each recommendation, so you always know which one is right.

A link that leaves the kit opens a page in the repository. In a printed or pasted copy, find that page there.

## Keep it private

Your filled-in pages stay in your binder or your own Docs folder, away from any public repository. Keep private details off every page. The rules are on the [privacy and safety](../../docs/privacy_and_safety.md) page.
