# Question Parking Lot

Copy this page out of the repository before you fill it in. Do not commit your filled-in work to a public repository.

The blank this page was copied from is the [Question Parking Lot template](../../templates/question_parking_lot.md). Start using it the first time a question tries to pull you off track. It keeps the session on course, so you still reach your Stop Point.

A question pops up. Chasing it would pull you off track. So park it here instead. This keeps your session focused. It also makes sure the question isn't lost. You can come back to parked questions any time. That includes while you wait for a grown-up.

One entry per question. Start a new copy of this table for each one:

| Prompt | Your answer |
| --- | --- |
| Question | |
| Why it matters | |
| Who can answer it? (me later / a grown-up / a source) | |
| Need it now, or later? (now / later) | |
| Status (parked / answered) | |

Parking a question is a real planner skill. It protects your focus and your Stop Point.
