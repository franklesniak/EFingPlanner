# Example: Trade-Off Report

This is a filled copy of the [Trade-Off Report](../templates/tradeoff_report.md). It's the pretend planner's route trade-off: keep two cities, or add a third.

**The decision I'm making:** Which route should we take?

| What I'm comparing | Option A | Option B | Option C (only if you need it) |
| --- | --- | --- | --- |
| What this option is | Route 1: Rome + Florence | Route 2: Rome + Florence + Venice | |
| Pros | More time in each city. Only one hotel move. | I get to see the canals and ride a water bus. | |
| Cons | We skip Venice this time. | Two hotel moves, and less time in Florence. | |
| Cost effect (higher / about the same / lower — not a price) | Lower | Higher, I think. The guidebook says hotels in Venice often cost more. | |
| Time effect | About the same trip length, with more time in each city | About the same trip length, but about half a day goes to the extra move | |
| Energy effect | Easier. Florence is small enough to walk. | Harder. We pack up twice, and Venice has lots of bridges with steps. | |
| Travel time (read it from the map's "Directions", don't guess from the map picture) | Rome to Florence: about an hour and a half by fast train | The same, plus Florence to Venice: about two hours by fast train | |
| What we would miss, or what gets skipped | Venice's canals and a boat ride | A full day in Florence, maybe the lookout hill | |
| Does this still fit our budget band? | I think so. Ask an adult. | Not sure. Ask an adult. | |
| Sources (also in my Source Log) | The map's Directions; library guidebook, page 52 | The map's Directions; library guidebook, page 88 | |
| What other source could check this? | The train company's official timetable | The train company's official timetable | |
| Verification source (the one I actually used to check) | The train company's official website, timetable page | The train company's official website, timetable page | |
| Date checked | April 2 | April 2 | |

**My recommendation:** Route 1, Rome + Florence.

**My reasons (two or three, each tied to something I found):**

1. The map's Directions showed that Venice adds a train ride of about two hours. With packing up and finding a new hotel, that's about half a day.
2. The guidebook says Florence is small enough to walk everywhere. That fits our family, because we like to walk slowly and stop a lot.
3. The dome is the sight I starred first. Route 1 gives it a whole fresh morning.

**What we give up by choosing it:** Venice, with its canals and a boat ride. I marked my Venice card "save for future", so it's ready for another trip.

**What a grown-up still needs to check or decide:** The train tickets and their prices, the hotel in Florence, and whether Route 1 fits our budget band.

## What to notice

- The cost row says "lower" and "higher", with no prices. That's all the row asks for.
- The travel times come from the map's Directions. The planner checked them again on the train company's official website, and wrote the date.
- Each reason ties back to something the planner found.
- The planner named what the family gives up. That's the hardest line to write, and the most useful one.
- The last box leaves the money and the hotel to a grown-up.
- Option C stays blank. Two options were enough.
