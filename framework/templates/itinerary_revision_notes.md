# Itinerary Revision Notes

This page is optional. Your decision log stays the main record of what changed in your plan, and why.

Some plans change many times. If yours does, this page keeps a short note for each change, all in one place. Then you can see how your plan grew. Use it only if it helps, and stop whenever you like.

One note per change. Start a new copy of this table for each one:

| Prompt | Your answer |
| --- | --- |
| Date of the change | |
| What changed | |
| Why it changed | |
| Who decided (a grown-up, the family, or me) | |
| Pages I fixed (from "Your plan pages" on the When the Plan Changes card) | |
| Is it in my decision log? (yes / not yet) | |

Keep exact booked dates off this page. If your dates got booked, write "dates booked" in the "What changed" row.

"Not sure yet" and "ask an adult" are fine answers in any row. The [When the Plan Changes](../student_guide/when_the_plan_changes.md) card says which pages to fix after a change. Your [Decision Record](decision_record.md) pages hold the decision itself.
