# Final Reflection

You fill this in at the finish line, in Session 53. Keep your baseline reflection next to you so you can compare. This is about noticing how you grew -- not about being perfect.

You can say your answers to an adult who writes them, or draw them, if that's easier.

| Prompt | Your answer |
| --- | --- |
| Date | |
| Looking back at my baseline: what is different now? | |
| My budget guess: did my Session 33 band check come out the way I expected? (Being off is normal. Grown-ups' first guesses are often off too.) | |
| What did I learn about planning? | |
| What was hard at first, and what helped me get started? | |
| What am I proud of? | |
| What are the grown-ups taking over now? | |
| Bridging: one planning move I used (like "start with one tiny step"). Where else could I use it: homework, a chore, a big project? | |

Some of these answers are a sentence or two, not just a word. Give yourself room. Write them in your binder or a Google Doc. There the space grows to fit. You don't have to squeeze a whole thought into a small printed box.

These are the same planning moves people use for homework and chores. They work for any big project too. Notice the move, and use it on purpose somewhere else. That's how it carries over.
