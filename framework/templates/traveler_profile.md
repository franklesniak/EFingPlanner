# Traveler Profile

Use one copy of this page per traveler, and write each person by relationship rather than by name. "A parent," "a grandparent," "a cousin," and "me" all work. Your Trip-Basics card holds the roster, so copy the list from there. Fill in what you know and leave the rest open. "Not decided yet" and "none known" are finished answers.

| Prompt | Your answer |
| --- | --- |
| Traveler role (by relationship, not by name) | |
| Preferences (how they like to travel) | |
| Constraints (anything that limits what they can do) | |
| Interests (what they want to see or try) | |
| Food interests (what they like, and anything they avoid) | |
| Preferred pace (busy days, slow days, or a mix) | |
| Stamina for long, busy days (high / medium / take it easy; "none known" is fine) | |
| Comfort with lots of walking and stairs on a busy day ("none known" is fine) | |
| Any sensory sensitivities: crowds, noise, bright or flashing light, food textures ("none known" is fine) | |
| Here for the whole trip, or only part? (Adults decide the exact dates.) | |
| One thing they might love | |
| One thing that might make the trip tiring | |
| Any needs the planner should design around: step-free access, an elevator, an accessible room, help with luggage ("none known" is fine) | |
| Questions to ask them | |

Three of these rows are pacing factors: stamina, walking and stairs, and sensory sensitivities. They decide how full a day can be, and you'll use them again in the pacing review.

**Keep medical specifics with the adults, off this page.** Write what someone needs designed around, never the medical reason behind it. Nobody has to explain why.

You can say your answers to an adult who writes them, or draw them, if that's easier.
